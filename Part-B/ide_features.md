# Introduction

My experience using an integrated development environment (IDE) to complete my first Python programming assignment helped me understand how important these tools are when writing code. I used GitHub to access and manage my project files and Visual Studio Code (VS Code) to work with and test my Python program. At first, learning where to enter the code and how to save and run the program was a little challenging, but following the steps helped me become more comfortable. Three IDE features that I found helpful were syntax highlighting, code completion, and debugging.

# Feature 1 – Syntax Highlighting

Syntax highlighting is a useful IDE feature because it displays different parts of the code in different colors. This makes the program easier to read and understand. While working on my birth-year program, I noticed that Python commands, variables, and text appeared in different colors. For example, the words input and print were easier to recognize because of the way the editor displayed the code. Syntax highlighting helps programmers organize their code visually and recognize potential mistakes more easily.

# Feature 2 – Code Completion

Code completion is another helpful feature because it suggests commands and programming statements while a person is typing. This can save time and reduce typing errors. While working in VS Code, code suggestions helped me become more familiar with Python commands and how they are written. For example, when working with input statements, suggestions can help identify the correct functions to use. This feature is especially useful for beginners because it helps them learn programming commands without having to remember everything.

# Feature 3 – Debugging

Debugging is important because it helps programmers find and correct problems in their code. When writing my birth-year program, I needed to make sure the program correctly accepted the user's name and age and calculated the birth year. Using VS Code to run and test the program helped me check whether the output was correct. Debugging helps programmers identify errors, understand what went wrong, and make corrections. This feature improves accuracy and helps programmers develop better problem-solving skills.

## Conclusion

Overall, using GitHub and VS Code helped me become more comfortable with writing and organizing Python code. I learned that IDE features such as syntax highlighting, code completion, and debugging can make programming easier and more efficient. As someone beginning to learn Python, I understand that these tools can help me avoid mistakes, improve my coding skills, and become more confident. I believe these features will also be useful as I continue working toward my cybersecurity degree and learning more advanced programming concepts.
